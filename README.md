# NSKeyboardLayoutSwitcher

Автоматический переключатель раскладки клавиатуры для Linux (X11). Программа запоминает раскладку для каждого окна и автоматически переключает её при смене активного окна.

## Управление

- Одиночное нажатие CapsLock: мгновенно переключает на английскую раскладку.
- Удержание CapsLock и нажатие Space: переключает на русскую раскладку, одновременно удаляя последний набранный символ (обычно пробел).
- Множественное нажатие Shift (от 2 до 10 раз): конвертирует последние слова в другую раскладку. 2 нажатия переводят одно последнее слово, 3 нажатия — два слова, и так далее. Конвертация работает в обе стороны (английский ↔ русский).
- Ctrl+Shift+Q: запоминает текущую раскладку активного окна.
- Ctrl+Shift+L: включает или выключает проверку орфографии.

## Пример работы

1. Открыть Firefox, переключиться на русскую раскладку, нажать Ctrl+Shift+Q.
2. Переключиться в терминал — раскладка автоматически сменится на английскую.
3. Вернуться в Firefox — раскладка снова русская.
4. Если в английской раскладке набрать «ghbdtn» и быстро нажать Shift два раза, текст заменится на «привет».
5. Если предварительно включить проверку орфографии (Ctrl+Shift+L), набрать «дорбый» в русской раскладке и дважды нажать Shift, текст заменится на «добрый».

## Требования для проверки орфографии

Для работы проверки орфографии необходим Python с установленным PySpellChecker и рядом с исполняемым файлом скрипт `spell_server.py`.

## Пример конфигурации

Файл `config.json` создаётся в директории запуска после первого старта программы.

```json
{
  "window_layout_map": {
    "firefox": 1,
    "yakuake": 0,
    "steam_proton": 1
  },
  "hotkeys": {
    "add_window": "ctrl shift q",
    "toggle_spell": "ctrl shift l"
  },
  "enable_spell_check": true,
  "python_interpreter": "/home/user/.venv/bin/python3"
}
